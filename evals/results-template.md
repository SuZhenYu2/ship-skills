# 校准执行记录模板

复制到 `evals/results/`，按[执行协议](calibration-cases.md#执行与取证)填写。正式对照每组每题至少 3 次；离线单题抽查只填实际执行次数。

- 日期：
- 模式 / 执行者：真实宿主对照或离线直接审查；是否已知评分标准
- 模型 / 版本：
- Runtime（Codex / DSH / 其他）与 skill 安装方式：
- 夹具来源：`bash evals/fixtures/build-fixtures.sh <target-dir>` 的构建时间与提交快照
- 对照基线（裸模型 / 对照 skill 集，如适用）：

| 用例 / 组 / 次序 | 目标 skill 调用（逐个） | 阻断（裁决 / 原因） | 业务测试（命令 / 结果） | 未知项 / 缺证原因 | 行为判定 / 命中标准 | 本次原始证据路径 |
| --- | --- | --- | --- | --- | --- | --- |
| | | | | | | |

每实际执行一次新增一行，不沿用上次结果。关联原始提示、实际答复、命令输出及前后状态；未知不留空、不按否处理。行为判定为 PASS / FAIL / 未知，不能代替前三项观测。

## 未覆盖范围

如实列出未运行的用例与原因（如缺夹具、缺外部依赖）。

## 结论

正式对照逐例列出 PASS / FAIL / 未知次数及通过率分母，单独说明退化。离线抽查只描述本次观察，不计算宿主通过率。
